---
name: pull-request
description: Create a GitHub PR if needed, commit and push the changes, and monitor the CI pipelines it triggers.
---

Can you:

1. Create a github PR if one doesn't already exist.
2. Commit and push your changes
3. Monitor any CICD pipelines that run as a result of your PR
4. If the pipelines fail, investigate the failure, fix the issue, and push the changes to the PR
5. Repeat steps 3 and 4 until the pipelines pass successfully.
